# weldchord

Weld URLs and chord query parts with stable normalization.

**Site:** https://theworker02.github.io/weldchord/

## Install / run

```bash
git clone https://github.com/theworker02/weldchord.git
cd weldchord
node src/cli.js
node --test
```
